## 🧩 Nível 1 — Introdução às listas
1.  Criando uma lista
- Crie uma lista com 5 nomes de alunos.
- Exiba a lista completa.
2.  Acessando elementos
- Dada a lista notas = [7.5, 8.0, 6.5, 9.0], mostre:
- A primeira nota
- A última nota
3.  Alterando valores
- Altere o segundo elemento da lista numeros = [10, 20, 30, 40] para 25.
4. Tamanho da lista
- Crie uma lista de frutas e mostre quantos itens ela possui.

## 🔁 Nível 2 — Operações básicas

5. Adicionar elementos
- Comece com uma lista vazia.
- Adicione 5 números usando append().

6. Remover elementos
- Dada a lista cores = ["azul", "verde", "vermelho", "amarelo"]
- Remova a cor "verde".
7. Verificar existência
- Peça ao usuário um nome.
- Verifique se ele está na lista de alunos.
8. Ordenação
- Dada uma lista de números, ordene em ordem crescente.

## 🔄 Nível 3 — Estruturas de repetição com listas
9. Percorrendo lista
- Crie uma lista com 5 números.
- Use for para exibir cada número.
10. Soma dos elementos
-Some todos os valores de uma lista.
11. Maior valor
- Encontre o maior número de uma lista.
12. Contagem
- Conte quantos números pares existem em uma lista.

##🧠 Nível 4 — Lógica aplicada
13. Média da turma
- Crie uma lista de notas.
- Calcule a média.
- Informe se a turma foi “Aprovada” (média ≥ 7).
14. Filtrar valores
- Dada uma lista de números, crie outra lista apenas com os números maiores que 10.
15. Lista invertida
- Inverta uma lista.
16. Remover duplicados
- Dada uma lista com valores repetidos, crie uma nova lista sem duplicatas.

## 💻 Nível 5 — Interação com usuário
17. Entrada de dados
- Peça ao usuário 5 números e armazene em uma lista.
18. Busca simples
- Após criar a lista, peça um número e informe se ele está presente.
19. Menu simples
- Crie um menu com opções:
- Adicionar número
- Remover número
- Mostrar lista
- Sair

## 🚀 Desafio final

- Permita que o usuário:
- Cadastre notas
