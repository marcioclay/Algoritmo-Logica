### Exercício 1: Gerador de Nome Completo
Conceitos: Variáveis, input(), concatenação / f-strings.

Instruções: Peça ao usuário para digitar seu primeiro nome e, em seguida, seu sobrenome. Exiba na tela o nome completo formatado, como em: "Nome completo cadastrado: [Nome] [Sobrenome]"

### Exercício 2: Soma de Dois Números Inteiros
Conceitos: Conversão de tipo (int), operador de adição (+).

Instruções: Solicite ao usuário dois números inteiros. Calcule a soma entre eles e exiba a mensagem: "A soma entre [número 1] e [número 2] é igual a [resultado]."

### Exercício 3: Área de um Retângulo
Conceitos: Conversão de tipo (float), operador de multiplicação (*).

Instruções: Peça ao usuário para digitar a base e a altura de um retângulo (números decimais). Calcule e mostre a área desse retângulo (Área = base × altura).

### Exercício 4: Divisão da Conta do Restaurante
Conceitos: Conversão de tipos (float, int), operador de divisão (/).

Instruções: Peça ao usuário o valor total da conta de um restaurante e a quantidade de pessoas na mesa. Calcule e exiba quanto cada pessoa deve pagar.

### Exercício 5: Conversor de Temperatura (Celsius para Fahrenheit)
Conceitos: Operadores aritméticos (*, /, +).

Instruções: Peça ao usuário uma temperatura em graus Celsius. Converta esse valor para Fahrenheit usando a fórmula:

Fahrenheit = (Celsius * 9 / 5) + 32

Exiba a temperatura convertida na tela.

### Exercício 6: Verificação de Senha
Conceitos: input(), operador relacional de igualdade (==).

Instruções: Peça ao usuário para digitar a palavra-chave de acesso. Compare o texto digitado com a senha correta "python123" e imprima o resultado booleano (True se for igual, False se for diferente).

### Exercício 7: Verificador de Temperatura Congelante
Conceitos: Conversão de tipo (float), operador relacional menor que (<).

Instruções: Peça ao usuário para informar a temperatura atual do ambiente em graus Celsius. O programa deve imprimir True se a temperatura estiver abaixo de zero (< 0) e False caso contrário.

### Exercício 8: Verificador de Múltiplo de 5
Conceitos: Operador de resto da divisão (%), operador relacional (==).

Instruções: Peça um número inteiro ao usuário. Verifique se o resto da divisão desse número por 5 é igual a zero. O programa deve imprimir True se o número for múltiplo de 5 e False caso não seja.

### Exercício 9: Teste de Intervalo Numérico
Conceitos: Operadores relacionais (>=, <=), operador lógico and.

Instruções: Peça ao usuário para digitar um número inteiro. Verifique se esse número está entre 10 e 50 (inclusive). O programa deve imprimir True se o número for maior ou igual a 10 E menor ou igual a 50, ou False caso esteja fora do intervalo.

### Exercício 10: Promoção de Frete Grátis
Conceitos: Operadores relacionais (>, ==), operador lógico or.

Instruções: Uma loja online oferece frete grátis se o valor total da compra for maior que R$ 100,00 OU se o cliente for membro VIP.

Peça o valor da compra (float).

Pergunte se o cliente é VIP pedindo para digitar "sim" ou "nao" (str).

Imprima True se a compra qualificar para frete grátis ou False caso contrário.
